# Cybersecurity-Portfolio
A collection of my cybersecurity walkthroughs, CTF writeups, and AI-assisted security scripts.

Welcome to my personal cybersecurity repository. Here, I document my practical learning journey, hands-on labs, and automation workflows. 

## Repository Structure

[Writeups](./Writeups/)**: Detailed, step-by-step walkthroughs for various CTF challenges (Hack The Box, TryHackMe, Root-Me, picoCTF). I use these to document my thought process and methodology.

[Scripts](./Scripts/)**: Practical security utilities. Since I focus heavily on operational security rather than heavy development, I leverage AI to generate these scripts, then manually review, debug, and use them for tasks like directory fuzzing and password filtering.

## Focus Areas

**Web Application Security:** Testing for OWASP Top 10 vulnerabilities (XSS, SQLi, JWT flaws).
**Digital Forensics:** Analyzing CTF forensics challenges, including artifact analysis, log investigation, network traffic inspection (PCAP files), and understanding steganography techniques.
**Offensive Automation:** Finding smart ways to speed up reconnaissance and information gathering using custom-tuned scripts.
**Active Directory:** Currently building foundational skills through the Certified Red Team Analyst (CRTA) pathway.

## Disclaimer
All writeups and tools within this repository are created strictly for educational purposes, legal CTF competitions, and authorized security assessments. I do not publish writeups for active/live machines in compliance with platform rules.
